# Johnson Electric Training Centre

A complete classroom management system for training centers.

## Features
- Student Management
- Test & Marks Entry
- Subject & Teacher Management
- Leave Records
- Discipline Tracking
- Mentor Meetings
- Comprehensive Reports
- Excel Import/Export
- PDF Reports

## Usage
- Data is stored locally in your browser's localStorage
- Export backup to JSON for data persistence
- Import Excel files for bulk student addition

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- SheetJS (XLSX)
- html2pdf.js
